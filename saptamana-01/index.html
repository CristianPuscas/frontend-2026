Despre mine

Cine sunt

Salut! Sunt o persoană pasionată de tehnologie și de dezvoltarea web. Îmi place să învăț lucruri noi și să descopăr cum sunt construite site-urile moderne. În timpul liber, încerc să-mi dezvolt abilitățile și să învăț prin practică.

Ce învăț

În prezent, învăț HTML, CSS și JavaScript pentru a putea crea site-uri web interactive și atractive. De asemenea, explorez diferite framework-uri și biblioteci care mă pot ajuta să îmi îmbunătățesc abilitățile de programare.

Scopul meu este să pot construi site-uri moderne, responsive și ușor de utilizat.

Tehnologii pe care le învăț

  • HTML
  • CSS
  • JavaScript
  • Webflow

Pașii mei de învățare

  1. Învăț bazele HTML.
  2. Studiez CSS și stilizarea paginilor.
  3. Exersez Flexbox și Grid.
  4. Construiesc primul meu site.
